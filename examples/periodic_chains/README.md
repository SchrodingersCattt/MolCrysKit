# Periodic-chain fixtures

These JSON requests exercise `mck build chain`. They are geometry fixtures,
not chemistry templates: charge, valence, force fields, and relaxation are
intentionally absent. Each request writes `structure.extxyz` and
`structure.json`. The set covers a synthetic non-zero-winding chain, a red
phosphorus local chain, a polyethylene-like chain, and an alpha-Se local chain.
