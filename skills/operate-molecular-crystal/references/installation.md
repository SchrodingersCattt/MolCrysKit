# Install MolCrysKit

Use the published PyPI package by default:

```bash
python -m pip install "molcrys-kit[desktop]"
```

For requested MolCrysKit source changes, install a checkout instead:

```bash
git clone https://github.com/SchrodingersCattt/MolCrysKit.git
cd MolCrysKit
python -m pip install ".[desktop]"
```
