# Changelog

## Unreleased

- Substitutive names that were previously treated as canonical and are not
  the standard spelling now fail closed. In particular `hex-2-one` is
  rejected; the canonical ketone name is `hexan-2-one`.
- Retained parents replace earlier non-retained spellings: `pyridine`,
  `naphthalene`, `furan`, `thiophene`, and `pyrrole`. Benzene polyols use
  the hydroxy suffix (`benzene-1,2-diol`). Monosubstituted ethane omits the
  locant (`chloroethane`). Nuclide labels use `(13C)methane` and
  `(2H4)methane`.
- Older spellings that still denote the same graph are accepted only as
  documented aliases, including `1,2-dihydroxybenzene`, `1-chloroethane`,
  and `1-azabenzene`.
